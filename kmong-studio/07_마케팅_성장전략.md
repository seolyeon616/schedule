# 07. 마케팅 & 성장 전략

## 1. 크몽 노출을 움직이는 변수 (운영자가 통제 가능한 것)
1. **응답 속도** — 1시간 이내 유지. 앱 푸시 필수
2. **리뷰 수·평점** — 첫 10개가 사실상 전부
3. **클릭률** — 썸네일·제목 (2주마다 A/B)
4. **전환율** — 상세페이지 + 첫 응답 품질
5. **납기 준수율 / 취소율** — 약속보다 하루 먼저 납품

## 2. 첫 30일 로드맵

| 기간 | 목표 | 액션 |
|---|---|---|
| D-7 ~ D0 | 입점 완성 | 포트폴리오 2편 완성(`04`) · 프로필/서비스 등록(`02`,`03`) · 심사 통과 |

## 3. 크몽 밖 유입 (크몽 서비스 링크로 연결 — 외부 거래 유도 아님)
- **인스타그램/유튜브 숏츠 계정 `@overframe.ai`**: 주 3회
  - 포맷 1: "이 광고, 촬영 0원입니다" — 완성본 + 스타일프레임 비교
  - 포맷 2: "프롬프트 한 줄 → 광고 한 컷" 과정 공개 (15초)
  - 포맷 3: 유명하지 않은 동네 가게를 무상으로 광고화 → 사장님 반응 (허락받고) → 바이럴 + 실제 리뷰 유도
- **스레드/링크드인**: 마케터 대상 "AI 광고 소재 A/B 결과" 인사이트 글 → 전문가 포지션
- 프로필 링크는 **크몽 서비스 페이지**로

## 4. 가격 전략
- 200 / 500 / 1,000(천원) 3단은 **가운데(DELUXE)를 팔기 위한 구조**. DELUXE에 ★추천 뱃지, PREMIUM은 앵커 역할
- 리뷰 20개 + 평점 4.9 이상 도달 시 → 250 / 600 / 1,200으로 인상 검토
- 실수령 계산: `판매가 × (1 − 크몽 판매 수수료율) − 툴 구독료 배분 − 세금` → 수수료율은 판매자 센터에서 구간별 확인 후 `/kmong-weekly`에 입력하면 자동 계산

## 5. 재구매 엔진
- 납품 시 "바이블"을 자산으로 남긴다 → 다음 의뢰는 바이블 재사용으로 빠르고 싸게 → 재구매 심리적 장벽 제거
- **월 정기 숏폼 패키지**(4편/월) — 반복 매출의 핵심. 3건 이상 재구매 고객에게 먼저 제안

## 6. 주간 루틴 (매주 월요일, `/kmong-weekly`)
- 지난주 문의 수 / 결제 수 / 전환율 / 평균 응답시간 / 매출
- 제목·썸네일 A/B 결과
- 경쟁사 1곳 신규 포트폴리오 확인 → 우리 아이디어 뱅크에 대응 컨셉 1개 추가
- 포트폴리오 1편 추가 (비어있는 업종부터)
