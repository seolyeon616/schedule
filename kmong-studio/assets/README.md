## 미니멀 세트 (애플 광고 톤 · 흰 배경 통일) — `apple/` ★ 현재 추천
| 파일 | 용도 |
|---|---|
| `apple/apple-thumb-main.png` | **대표 썸네일** (촬영 없이. 광고를 뚝딱. + 실제 제작 장면) |
| `apple/apple-thumb-many.png` · `-allinone` · `-sample` · `-stats` | 추가 썸네일 4장 |
| `apple/apple-full.jpg` | **크몽 서비스 설명 맨 위 상세 이미지 한 장** (2배 해상도) |

디테일: 흰 배경 + 영상 장면만 둥근 검정 카드, 금색은 핵심 단어 1곳, `›` 링크, 숫자 스펙 블록(∞ · 0원 · 2컷 · 3일), 각주 ¹². 가격 숫자 없음.
원본: `src/apple.html` (`PAGE=apple.html node render.mjs`). 사진은 실제 제작한 「물의 기억」 1번 컷 프레임입니다.

## ⚠️ 포트폴리오 영상이 완성되면 교체할 것
`d06`(시그니처 필름)과 썸네일 안의 장면 프레임은 **일러스트로 그린 시안**입니다.
`04_포트폴리오_영상_기획.md`로 실제 영상을 만든 뒤, 영상에서 뽑은 실제 스틸로 바꾸면 신뢰도가 크게 올라갑니다.
(`src/index.html`에서 `<use href="#scPerfume"/>` 같은 부분을 `<image href="스틸.jpg" .../>`로 바꾸고 다시 렌더링)

## 수정 후 다시 만들기
```bash
cd kmong-studio/assets/src
npm i
npm i --no-save playwright   # 또는 전역 playwright 사용
node render.mjs              # 전체
node render.mjs thumb-main   # 특정 이미지만
```
문구·가격이 바뀌면 `src/index.html`만 고치면 모든 이미지에 반영됩니다.
