# 06. 고객 응대 스크립트

> 원칙: **빠르게(1시간 이내) · 구체적으로 · 먼저 제안하기.**
> 고객은 "잘 만들어요"가 아니라 "내 브랜드를 이미 생각해봤네"에 결제한다.
> 크몽 규정상 외부 연락처(전화·카톡·이메일) 교환·외부 결제 유도 금지. 모든 소통은 크몽 메시지 안에서.
> 대괄호 `[ ]`는 채워 넣을 부분. 상황이 애매하면 원문을 `/kmong-reply`에 붙여넣으세요.

---

## 0. 부재 시 자동 응답
```
안녕하세요, OVERFRAME AI STUDIO입니다 :)
지금 제작에 집중하고 있어 확인 후 빠르게 답변드리겠습니다.

기다리시는 동안 아래 3가지만 남겨주시면 바로 방향 제안까지 드릴게요.
1) 브랜드/제품 한 줄 소개
2) 영상 사용처 (유튜브 광고 / 릴스·숏츠 / 홈페이지 / 행사 등)
3) 희망 납품일
```

## 1. 첫 문의 응답 (가장 중요 — 무료 방향 제안 포함)
```
안녕하세요 [고객명]님, OVERFRAME AI STUDIO입니다.
[제품/브랜드] 영상 문의 감사드립니다.

말씀 주신 내용 기준으로 바로 떠오른 방향 3가지 먼저 드려볼게요.

A. [컨셉명] — [한 줄 설명]
B. [컨셉명] — [한 줄 설명]
C. [컨셉명] — [한 줄 설명]

[사용처] 용도라면 [추천 패키지]가 가장 잘 맞습니다.
· [길이] / [비율] / 작업일 [N]일
· 본 제작 전 스타일프레임을 먼저 보여드려서, 결과물을 미리 확인하고 진행하실 수 있어요.

혹시 참고하고 싶은 영상이나 꼭 들어가야 할 장면이 있으시면 알려주세요.
마음에 드는 방향이 있으시면 그 방향으로 더 구체화해서 보내드리겠습니다.
```

## 2. 가격 문의 / 할인 요청
```
[고객명]님, 솔직하게 말씀드리면 저희 가격에는 영상 1편이 아니라
기획안 · 스타일프레임 선공개 · [리컷/스틸 등 포함 항목]까지 포함되어 있어서
따로 맡기시는 것보다 전체 비용은 오히려 적게 드시는 구조예요.

예산이 [금액]이시라면 이렇게 조정해 드릴 수 있습니다.
· 길이를 [N]초로 줄이고 핵심 컷에 집중
· 리컷 대신 본편 퀄리티에 예산 집중
어느 쪽이 목적에 더 맞으실지 말씀해주시면 맞춰서 구성해 드릴게요.
```
(가격을 깎기보다 **범위를 조정**한다. 첫 5건 리뷰 확보 기간에는 `07` 문서의 런칭 혜택 사용)

## 3. 결제 완료 직후
```
[고객명]님, 결제 확인했습니다. 감사합니다!
지금부터 [패키지명] 제작을 시작합니다.

■ 진행 일정 (작업일 기준)
· [날짜] 기획안 전달 → 컨펌
· [날짜] 스타일프레임 전달 → 컨펌
· [날짜] 러프컷 전달 → 컨펌
· [날짜] 최종 납품
※ 컨펌 대기 기간은 작업일에서 제외됩니다.

아래 질문에 편하게 답해주시면 바로 기획에 들어가겠습니다. (5분이면 충분해요)
1. 영상을 본 사람이 해야 할 행동 하나
2. 분위기 키워드 3개
3. 반드시 들어갈 문구/로고/제품 컷
4. 피하고 싶은 느낌
5. 제품 사진/로고 파일 (있으시면)
```

## 4. GATE 1 — 기획안 전달
```
[고객명]님, 기획안 전달드립니다.

■ 핵심 전략 한 줄: [전략]
■ 추천안: [컨셉명] — [추천 이유]
(첨부: 기획안 · 스토리보드)

확인하실 포인트는 3가지예요.
① 컨셉 방향이 브랜드와 맞는지
② 장면 흐름
③ 카피 문구

이 단계에서 확정해 주시면 다음 단계에서 실제 장면의 룩을 스틸로 보여드리겠습니다.
기획 확정 이후 컨셉 자체의 변경은 재기획으로 별도 협의가 필요한 점 참고 부탁드려요.
```

## 5. GATE 2 — 스타일프레임 전달
```
[고객명]님, 실제 영상의 핵심 장면을 스틸로 먼저 보여드립니다.
(첨부: 스타일프레임 [N]장)

이 장면들이 그대로 움직이는 영상이 된다고 보시면 됩니다.
색감 · 조명 · 인물/제품 느낌에서 조정하고 싶은 부분 있으시면 지금 말씀해주세요.
이 단계에서 조정하는 것이 가장 빠르고 정확합니다.
```

## 6. GATE 3 — 러프컷 전달
```
[고객명]님, 러프컷입니다.
(첨부: 러프컷 영상)

※ 러프컷은 흐름과 타이밍 확인용이라 색보정·음악 믹스·업스케일은 최종본에서 완성됩니다.
확인 포인트: 장면 순서 · 컷 길이 · 자막 문구 · 음악 분위기

수정 사항은 [00:12] 처럼 시간과 함께 적어주시면 정확하게 반영하겠습니다.
(현재 수정 가능 횟수: [N]회 중 [N]회 남음)
```

## 7. 수정 요청 대응
**범위 안:**
```
네 [고객명]님, 말씀하신 [N]가지 반영해서 [날짜/시간]까지 전달드리겠습니다.
1. [00:05] [수정 내용] → [반영 방법]
2. ...
```
**범위 밖(컨셉 변경):**
```
[고객명]님, 말씀하신 부분은 기획 단계에서 확정된 [장면/컨셉] 자체를 바꾸는 작업이라
재생성과 재편집이 필요해 수정 범위를 넘어서는 부분이에요.

대신 두 가지 방법을 제안드릴게요.
A. 현재 컨셉 안에서 [대안]으로 비슷한 효과를 내는 방법 (추가 비용 없음)
B. 해당 장면 재기획·재제작 (추가 옵션 [금액])
어느 쪽이 좋으실지 말씀 주세요.
```

## 8. 일정 지연이 예상될 때 (먼저 말하기)
```
[고객명]님, 미리 말씀드릴 부분이 있어 연락드립니다.
[장면]의 퀄리티를 기준치까지 끌어올리는 데 시간이 조금 더 필요해 [원래 날짜] → [새 날짜]로 전달드리려 합니다.
기다려 주시는 대신 [보너스: 스틸 1장 추가 / 훅 버전 1종 추가]를 함께 드리겠습니다.
일정이 촉박하시면 말씀 주세요. 우선순위 조정해서 맞춰 보겠습니다.
```

## 9. 최종 납품
```
[고객명]님, 최종 결과물 납품드립니다 🎬

■ 납품 구성
· 본편 16:9 ([길이]) — 4K / FHD
· [리컷/컷다운/훅/스틸 구성]
· 자막 파일 (.srt)
· 플랫폼별 업로드 가이드

■ 활용 팁
· 유튜브 광고는 [훅 A], 인스타 릴스는 [훅 B]로 먼저 테스트해 보시는 걸 추천드려요.
· 2주 정도 집행 후 반응 좋은 훅을 알려주시면 다음 소재 기획에 반영해 드립니다.

작업하는 동안 [브랜드]를 깊이 들여다볼 수 있어 저희도 즐거웠습니다.
확인 후 구매확정 부탁드리며, 만족하셨다면 짧은 후기 한 줄이 저희에게 정말 큰 힘이 됩니다.
```

## 10. 구매확정 후 (재구매 유도, 7~14일 뒤)
```
[고객명]님, 지난번 [영상명] 반응은 어떠셨나요?
혹시 새 시즌이나 다음 프로모션 준비 중이시면, 기존 바이블(모델·제품·톤)을 그대로 활용해서
더 빠르고 저렴하게 후속 소재를 만들어 드릴 수 있어요.
월 정기 숏폼 패키지도 있으니 필요하실 때 편하게 말씀 주세요.
```

## 11. 거절해야 할 의뢰
```
[고객명]님, 문의 감사드립니다.
말씀하신 [실존 인물 얼굴/목소리 합성 · 타사 로고/캐릭터 사용 등]은 초상권·저작권 문제와
크몽 운영 정책상 제작이 어렵습니다.
대신 [브랜드 전용 가상 모델 / 오리지널 캐릭터]로 같은 효과를 내는 방향을 제안드릴 수 있어요.
원하시면 바로 시안 방향 잡아드리겠습니다.
```

## 12. 리뷰 답글 원칙
- 리뷰 답글은 **다음 고객이 읽는 광고**. 고객 이름보다 "어떤 문제를 어떻게 해결했는지"를 쓴다.
- 불만 리뷰: 변명 X → 인정 1줄 + 개선한 공정 1줄 + 감사 1줄
```
[긍정] [브랜드]의 [핵심 특징]을 [장면/연출]로 풀어내는 작업이라 저희도 즐거웠습니다.
스타일프레임 단계에서 방향을 빠르게 잡아주신 덕분에 [결과]까지 이어질 수 있었어요.
다음 캠페인에서도 바이블 그대로 이어서 도와드리겠습니다. 감사합니다!

[부정] 말씀 주신 [문제]는 저희가 더 챙겼어야 하는 부분이었습니다.
이후로는 [개선한 공정]을 추가해 같은 일이 생기지 않도록 하고 있습니다.
솔직한 후기 감사드립니다.
```
