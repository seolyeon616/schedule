## Claude 단축 명령어 (Claude Code에서 이 저장소를 열면 사용 가능)

| 명령 | 하는 일 |
|---|---|
| `/kmong-new` + 고객 메시지 붙여넣기 | 의뢰 분석 → 추천 패키지·견적 → 첫 답장 → 고객 폴더 생성 |
| `/kmong-plan 고객명` | 크리에이티브 전략 + 컨셉 3안 + 스토리보드 |
| `/kmong-prompts 고객명` | 샷별 이미지·영상·사운드 프롬프트 전체 |
| `/kmong-reply` + 고객 메시지 | 상황에 맞는 프로 응대 답장 |
| `/kmong-deliver 고객명` | 납품 전 QC 체크 + 납품 메시지 + 리뷰 유도 |
| `/kmong-review` + 리뷰 내용 | 리뷰 답글 (다음 고객이 읽는 광고로 작성) |
| `/kmong-weekly` | 주간 운영 리포트 + 개선 액션 |

## 사용 흐름 (매 의뢰)

```
크몽 메시지 도착
  → 메시지 복사 → Claude에 /kmong-new 붙여넣기
  → 답장 복사 → 크몽에 전송
  → 결제 완료 → /kmong-plan → 기획안 PDF/이미지로 고객 컨펌
  → /kmong-prompts → 툴에서 생성 → 편집
  → /kmong-deliver → 납품
  → 리뷰 달리면 /kmong-review
```

> ⚠️ Claude는 크몽 계정에 직접 로그인하거나 메시지를 자동 전송할 수 없습니다.
> 크몽 ↔ Claude 사이의 **복사/붙여넣기**만 사람이 하고, 나머지 판단·작성·기획은 전부 여기서 처리합니다.
