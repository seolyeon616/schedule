# 09. 운영 규칙 & 리스크 체크

## 절대 하지 않는 것
- [ ] 실존 인물(연예인·정치인·일반인)의 얼굴·목소리 합성 — 딥페이크·초상권·선거법 위반 소지. 크몽 정책상 금지
- [ ] 타사 로고·캐릭터·상표 무단 사용 (고객이 권리자임을 증명한 경우만)
- [ ] 무료 플랜/비상업 라이선스 툴 산출물 납품
- [ ] 크몽 외부 연락처 교환·외부 결제 유도 (계정 제재 사유)
- [ ] 허위 경력·자격 기재, 타인 작품을 포트폴리오로 사용
- [ ] 의료·건강기능식품의 효능 과장 표현 (식약처 광고 규정) — 카피는 고객이 최종 책임, 우리는 위험 문구 먼저 고지

## 사업자 · 세금계산서
- [ ] 개인으로 시작 가능. 기업 고객·맞춤 견적이 늘면 개인사업자 등록(업태: 서비스 / 종목: 영상 제작) → 세금계산서 발행
- [ ] 크몽의 세금계산서·현금영수증 발행 절차를 판매자 센터에서 확인
- [ ] 방송·옥외 집행 건: 매체사 광고 심의와 AI 생성물 표기 기준을 집행 전에 고객에게 안내
- [ ] IP 소유권 이전(맞춤 견적 건): 이전 범위(가상모델 이미지·세계관 문서·프롬프트)를 크몽 메시지에 텍스트로 확정

## 분당 요금제 분쟁 예방
- [ ] "컷수 무제한" = 영상 길이 안의 장면 수 제한·추가금 없음. **수정 무제한이 아님**을 상세페이지·첫 응답·FAQ에 같은 문장으로
- [ ] "성우 포함" = 프리미엄 AI 보이스. 실제 사람 성우는 옵션
- [ ] 분 쪼개기는 15초 단위, 편 구성은 결제 직후 질문지에서 확정 (나중에 편 수 변경 = 재기획)

## 의뢰마다 확인
- [ ] 고객 제공 자료(제품 사진·로고·음원)의 권리 확인 문구를 메시지로 남김
- [ ] 사용한 툴 & 플랜 기록 (`clients/고객/license.md`)
- [ ] BGM 생성 플랜의 상업 이용 조건 캡처
- [ ] AI 생성물 표시 의무가 있는 플랫폼/매체인지 확인 (광고 집행 매체별 정책 안내)

## 분쟁 예방
- 모든 합의는 크몽 메시지에 텍스트로 남긴다 (분쟁 조정 시 유일한 증거)
- 게이트 컨펌은 "확정합니다" 같은 명시적 답을 받고 다음 단계로
- 추가 비용은 반드시 크몽 **맞춤 견적/옵션**으로 결제받은 뒤 작업
