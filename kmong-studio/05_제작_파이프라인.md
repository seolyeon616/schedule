# 05. 제작 파이프라인 — 의뢰 1건 표준 공정

## 1. 공정 7단계 + 컨펌 게이트 3개

```
[0] 문의 ─ 결제 전 무료 시안 1컷 (스틸, 업종별 템플릿으로 30분 이내 제작)
[1] 결제 → 브리프 수집 (03 문서 8번 질문지)
[2] 기획 ─ 전략 한 장 + 컨셉 N안 + 스토리보드 + 카피      ◆ GATE 1: 기획 컨펌
[3] 바이블 ─ 제품/인물/컬러 레퍼런스 시트 생성
[4] 스타일프레임 + 애니매틱(DELUXE↑) ─ 룩과 흐름         ◆ GATE 2: 룩 컨펌
[5] 생성 ─ Image-to-Video, 컷당 4~8회 → 베스트 선택
[6] 러프컷 ─ 편집·가(假)사운드·자막                     ◆ GATE 3: 흐름 컨펌
[7] 파이널 ─ 색보정·사운드 믹스·업스케일·리컷·QC → 납품
```
게이트를 통과한 내용은 이후 "수정"이 아니라 "변경"으로 간주 → 수정 분쟁 차단.
각 게이트 메시지 템플릿은 `06` 문서 참고.

## 2. 패키지별 일정 (분당 요금제)

| 단계 | 숏컷 · 2일 | 1분 · 3일 | 2분 · 5일 | 3분 · 7일 |
|---|---|---|---|---|
| 질문지 → 대본·콘티 (GATE 1) | D1 | D1 | D1 | D1–2 |
| 바이블·스타일프레임 (GATE 2는 무료 시안으로 대체 가능) | D1 | D1 | D2 | D3 |
| 생성 (컷당 재생성 4회 이내) | D1–2 | D2 | D3–4 | D4–5 |
| 편집·성우·BGM·자막 → 1차 전달 | D2 | D3 | D5 | D6 |
| 수정 반영·최종 | 수정 기간 별도 | | | D7 |

> 회전율 원칙: 1분 제작 시간 3시간 이내. 고객 컨펌 대기 시간은 작업일에서 제외.
> 대형 맞춤 견적(캠페인·방송 규격)은 이전 3단 게이트(기획→스타일프레임→러프컷)를 그대로 사용.

## 4. 프롬프트 공식

### 이미지 (스타일프레임)
```
[피사체 + 구체적 디테일] , [행동/상태] , [장소/배경] , [빛: 방향·색·질감] , [렌즈/앵글] , [무드 키워드 2개] , [매체: commercial photography / film still] , [공통 접미사]
```

### 영상 (Image-to-Video)
```
[카메라 움직임 1개] + [피사체의 움직임 1~2개] + [환경의 움직임(바람·물·빛)] + [속도감: slow motion / real-time] + [무드] + [사운드 힌트(오디오 생성 모델일 때)]
```
규칙:
1. **카메라 움직임은 컷당 하나.** (push-in, orbit, tracking, crane, FPV 중 택1)
2. 5~8초 단위로 생성 → 편집에서 잘라 쓴다. 길게 뽑을수록 붕괴 확률↑
3. 인물 컷은 "움직임 최소 + 표정 변화 1개"가 가장 고급스럽다
4. 손·글자·군중은 AI 약점 → 화면에서 작게, 짧게, 또는 편집 합성
5. 트랜지션 컷은 **끝 프레임을 다음 컷의 첫 프레임으로** 지정 (start/end frame 기능)

### 네거티브 체크 (프롬프트에 넣거나 재생성 기준으로)
`distorted hands, extra fingers, warped face, flickering, morphing product, text, watermark, logo artifacts, jitter`

## 5. 일관성 바이블 만드는 법
1. **제품**: 고객 제품 사진 → 배경 제거 → 정면/45°/측면 3장 레퍼런스 시트
2. **인물**: 가상 모델 1명 정면 클로즈업 1장을 "원본"으로 확정 → 모든 인물 컷에 캐릭터 레퍼런스로 첨부
3. **컬러**: 헥스 코드 3개 + 빛 방향을 모든 프롬프트에 동일 문장으로 삽입
4. **바이블 문장**: 한 문단짜리 "세계관 문장"을 만들어 모든 프롬프트 앞에 복붙

## 6. 납품 QC 체크리스트
- [ ] 영상 길이·비율·해상도가 패키지와 일치
- [ ] 1프레임 단위 스크럽: 손·얼굴·제품 왜곡 없음
- [ ] 로고·문구 철자 (고객 제공 원문과 대조)
- [ ] 오디오 피크 -1dB 이하, 대사 명료
- [ ] 9:16 리컷 세이프존 (상단 14%, 하단 20%)에 핵심 요소 없음
- [ ] 파일명 규칙: `브랜드_컨셉명_길이_비율_v최종.mp4`
- [ ] 음원·툴 라이선스 증빙 스크린샷 보관 (고객 폴더 `license/`)
