## 1. 닉네임 (한 번 정하면 변경이 어려움 — 신중히)

**추천: `오버프레임AI스튜디오`** (영문 병기: OVERFRAME AI STUDIO)
- 의미: "프레임을 넘어서" — 영상 한 컷을 넘어 캠페인을 만든다
- 대안: `프리즘필름AI` / `루멘랩스튜디오` / `시퀀스랩AI`

## 2. 프로필 사진
- **로고형 권장** (개인 얼굴보다 스튜디오 신뢰도↑): 검정 배경 + 흰색 프레임 사각형이 한쪽 모서리에서 "깨져 나가는" 미니멀 심볼
- 로고 생성 프롬프트 (Midjourney / 이미지 생성 AI):
```
minimalist logo mark, a thin white rectangular film frame whose top-right corner breaks outward into light particles, pure black background, premium tech studio identity, flat vector, centered, lots of negative space --ar 1:1 --style raw
```

## 3. 한 줄 소개 (헤드라인)
```
광고대행사 기획력 × 생성형 AI | 영상 한 편이 아닌 '캠페인 한 세트'를 납품합니다
```
대안:
- `본 제작 전 스타일프레임으로 먼저 보여드립니다 | AI 광고·브랜드 필름 스튜디오`
- `1.5초 안에 멈추게 하는 AI 광고 영상 | 기획·제작·숏폼 리컷까지 원스톱`

## 4. 전문가 소개 (자기소개 본문)
```
안녕하세요, OVERFRAME AI STUDIO입니다.

저희는 "AI로 영상을 만드는 곳"이 아니라
"광고가 되는 영상을 AI로 설계하는 곳"입니다.

■ 이렇게 다릅니다
① 스타일프레임 선공개
   본 제작 전에 실제 영상의 한 장면을 스틸로 먼저 보여드립니다.
   색감·분위기·연출을 눈으로 확인하고 확정한 뒤 제작하니, 결과물이 기대와 어긋나지 않습니다.

② 캠페인 킷 납품
   16:9 본편 하나로 끝나지 않습니다.
   9:16 숏폼 리컷, 15초 컷다운, 훅 A/B 버전, 키비주얼 스틸까지 — 바로 광고를 집행할 수 있는 구성으로 드립니다.

③ 성과 설계
   첫 1.5초 훅, 무음 재생에서도 읽히는 자막 구조, 유튜브·인스타·메타 광고 세이프존까지 고려해 제작합니다.

④ 일관성 바이블
   AI 영상의 고질병인 "컷마다 얼굴·제품이 바뀌는 문제"를 레퍼런스 시트로 고정합니다.

■ 작업 분야
브랜드 필름 · 제품 광고 · 런칭 티저 · 숏폼 광고 · 가상 모델 광고 · 공간/부동산 홍보 · 기업 IR/비전 영상 · 뮤직비디오 · 교육/공공 홍보

■ 진행 방식
문의 → 무료 방향 제안 → 결제 → 기획안 컨펌 → 스타일프레임 컨펌 → 러프컷 컨펌 → 최종 납품
각 단계마다 확인받고 넘어가므로, 처음 AI 영상을 맡기시는 분도 안심하고 진행하실 수 있습니다.

■ 응답
평일 10:00~22:00 / 주말 문의도 순차 답변드립니다.

지금 떠오르는 아이디어가 한 줄뿐이어도 괜찮습니다.
그 한 줄을 캠페인으로 만들어 드리겠습니다.
```

## 5. 전문가 정보 항목

| 항목 | 입력값 |
|---|---|
| 전문 분야(대분류) | 영상·사진·음향 → AI 영상 |
| 세부 분야 | AI 광고 영상, AI 브랜드 영상, AI 숏폼, AI 모델 영상 |
| 경력 | 실제 경력만 기입 (영상/디자인/마케팅/광고 관련 경력이 있으면 연차와 함께). 없으면 비워두고 포트폴리오로 증명 |
| 보유 기술(스킬 태그) | 생성형 AI 영상, 프롬프트 엔지니어링, 광고 기획, 스토리보드, 영상 편집, 모션그래픽, 사운드 디자인, 색보정, 숏폼 마케팅 |
| 사용 툴 | Google Veo, Kling, Runway, Midjourney, Adobe Premiere Pro / After Effects, DaVinci Resolve, CapCut, ElevenLabs, Suno (**실제 사용하는 것만** 남기기) |
| 활동 지역 | 전국 (비대면) |
| 연락 가능 시간 | 10:00 ~ 22:00 |
| 평균 응답 시간 목표 | **1시간 이내** (크몽 노출 지표에 영향) |
| 자격증/학력 | 실제 보유분만 (없으면 공란 — 허위 기재는 크몽 제재 대상) |

## 6. 포트폴리오 등록 순서 (첫 인상 = 첫 3개)
1. **대표작 A — 제품 광고형** (`04` 문서의 FILM 01)
2. **대표작 B — 브랜드 필름형** (`04` 문서의 FILM 02)
3. **캠페인 킷 쇼케이스** — 대표작 A의 16:9 / 9:16 / 스틸 5장을 한 장 콜라주로 → "한 번 주문하면 이만큼 받는다"를 시각화
4. **비포/애프터** — 고객 원본 제품 사진 1장 → AI 광고 컷 (신뢰 형성용)
5. **스타일프레임 → 완성 영상 비교** — 우리 공정 자체를 포트폴리오로

포트폴리오 제목 규칙: `[업종] 컨셉명 | 길이 · 비율` 예) `[코스메틱] 물의 기억 | 45초 · 16:9`

## 7. 입점 당일 체크리스트
- [ ] 전문가 전환 + 본인인증 + 정산 계좌 등록
- [ ] 사업자 여부 결정 (개인 → 추후 매출 증가 시 사업자 전환, 세금계산서 요청 대응)
- [ ] 닉네임·사진·한 줄 소개·소개 본문
- [ ] 포트폴리오 최소 3개 (영상 2 + 쇼케이스 1)
- [ ] 서비스 등록 (`03` 문서) → 크몽 심사 대기 (보통 영업일 기준 수일)
- [ ] 크몽 앱 설치 + 메시지 푸시 알림 ON (응답 속도 = 노출)
- [ ] 자동 응답(부재 시) 문구 등록 → `06` 문서 0번
