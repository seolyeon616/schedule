# 뚝딱컷 크몽 입점 작업 지시서 (Claude in Chrome 전용)

> 이 파일 하나만 Claude in Chrome에 주면, 사용자의 크롬(크몽 로그인 상태)에서 입점 세팅을 처음부터 끝까지 진행할 수 있도록 만든 문서입니다.
> 입력할 문구는 전부 이 파일 아래쪽 **[부록 A] 프로필**, **[부록 B] 서비스 등록**에 원문 그대로 들어 있습니다.
> 크몽 화면 구성·메뉴 이름은 바뀔 수 있습니다. 화면에 보이는 이름을 기준으로 가장 가까운 칸에 넣으세요.

## 0. Claude가 반드시 지킬 규칙

1. **되돌리기 어려운 버튼은 누르기 전에 멈추고 사용자에게 확인받는다.**
   - "등록", "제출", "검수 요청", "저장 후 공개", "메시지 전송", "견적 발송", "주문 수락/거절", "환불", "구매확정 요청"
2. **절대 하지 않는다:** 비밀번호·계정 정보·정산 계좌·본인인증·결제 정보 입력이나 변경 (사용자가 직접)
3. **크몽 밖 연락처를 적지 않는다:** 전화번호, 카카오톡 ID, 이메일, 외부 링크 (크몽 규정 위반 → 계정 제재)
4. 문구는 **부록 원문 그대로** 넣는다. 글자 수 제한에 걸리면 뜻을 유지한 채 줄이고, 줄인 문장을 사용자에게 보여준다.
5. 모르는 칸(사업자 정보, 경력, 자격증 등)은 **지어내지 않고 비워 둔 뒤** 사용자에게 묻는다.
6. 파일 업로드 창(내 PC 파일 선택)은 Claude가 조작하기 어려울 수 있다 → 어떤 파일을 어떤 순서로 올릴지 안내하고, 선택은 사용자가 한다.
7. 각 단계가 끝날 때마다 **무엇을 입력했는지 짧게 보고**한다.

## 5. 매일 운영 (주문·메시지)

### 5-1. 부재 시 자동 응답 (한 번만 등록)
```
안녕하세요, AI 광고 스튜디오 뚝딱컷입니다 :)
지금 제작에 집중하고 있어 확인 후 빠르게 답변드리겠습니다.

기다리시는 동안 아래 3가지만 남겨주시면 바로 방향 제안까지 드릴게요.
1) 브랜드/제품 한 줄 소개
2) 영상 사용처 (유튜브 광고 / 릴스·숏츠 / 홈페이지 / 행사 등)
3) 희망 납품일
```

### 5-2. 새 메시지가 오면
1. 크몽 메시지함에서 **안 읽은 대화**를 연다
2. 고객 원문을 읽고 **답장 초안**을 쓴다. 기준:
   - 첫 답장엔 반드시 가격 안내 문장 포함:
     > 뚝딱컷은 계산이 하나뿐입니다. 영상 길이(분) × 150,000원이 최종 금액이고, 컷 수 제한 없이 AI 성우 내레이션·대본·BGM·효과음·자막까지 전부 포함입니다. 15초보다 짧은 영상 한 편이면 숏컷(75,000원)으로도 가능합니다.
   - 고객 업종에 맞는 **컨셉 한 줄 3개** 제안 + 추천 패키지 + "결제 전에 무료 시안 1컷을 먼저 보내드릴게요"
   - 할인 요청 → 할인 대신 길이 조정·분 쪼개기 제안
   - 실존 인물·연예인 합성, 타사 로고 요청 → 정중히 거절하고 가상 모델 제안
3. ⏸ 초안을 입력창에 넣고 **전송 전 멈춤** → 사용자 확인 후 전송
4. 대화 내용을 사용자에게 요약 보고 (저장소 `kmong-studio/clients/<고객명>/log.md`에 기록하도록)

### 5-3. 하지 않는 것
- 주문 수락·거절·취소·환불, 견적서 발송, 금액 변경은 **사용자 확인 없이 누르지 않는다**
- 고객에게 파일 링크(구글드라이브 등)를 보내지 않는다 — 크몽 안 파일 첨부만

## 1. 닉네임
**`뚝딱컷스튜디오`** (크몽 닉네임 · `뚝딱컷`은 이미 사용 중이라 불가) / 브랜드 표기는 계속 **뚝딱컷** (영문: TTUKTTAK CUT)
- 의미: "금 나와라 뚝딱" 하면 나오는 도깨비 방망이처럼, 말 한 줄로 광고 한 편이 나온다
- 원칙: "뚝딱"은 **고객이 편하다는 뜻**으로만 쓰고(대충이라는 뜻이 아님), 제작 공정은 치밀하다는 것을 항상 함께 보여준다
- 슬로건: **촬영 없이, 방송급 광고를 뚝딱.**
- 서브 슬로건: `고객님은 한 줄, 나머지는 뚝딱컷이.`

## 2. 프로필 사진 (로고)
- 심볼: 미니멀한 **도깨비 방망이 실루엣**. 방망이의 돌기를 **필름 스프로킷 구멍**으로 재해석
- 컬러: 블랙 배경 + 골드 `#D9B77E`
- 로고 생성 프롬프트:
```
minimalist logo mark, a sleek modern Korean dokkaebi club (magic club) silhouette where the club's studs are reinterpreted as film sprocket holes, a tiny spark of golden light at the tip, gold line on pure black background, premium creative studio identity, flat vector, centered, generous negative space --ar 1:1 --style raw
```
- 워드마크: `뚝딱컷` 굵은 산세리프 (Pretendard Black), 자간 -2%
