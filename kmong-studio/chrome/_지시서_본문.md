# 뚝딱컷 크몽 입점 작업 지시서 (Claude in Chrome 전용)

> 이 파일 하나만 Claude in Chrome에 주면, 사용자의 크롬(크몽 로그인 상태)에서 입점 세팅을 처음부터 끝까지 진행할 수 있도록 만든 문서입니다.
> 입력할 문구는 전부 이 파일 아래쪽 **[부록 A] 프로필**, **[부록 B] 서비스 등록**에 원문 그대로 들어 있습니다.
> 크몽 화면 구성·메뉴 이름은 바뀔 수 있습니다. 화면에 보이는 이름을 기준으로 가장 가까운 칸에 넣으세요.

---

## 0. Claude가 반드시 지킬 규칙

1. **되돌리기 어려운 버튼은 누르기 전에 멈추고 사용자에게 확인받는다.**
   - "등록", "제출", "검수 요청", "저장 후 공개", "메시지 전송", "견적 발송", "주문 수락/거절", "환불", "구매확정 요청"
2. **절대 하지 않는다:** 비밀번호·계정 정보·정산 계좌·본인인증·결제 정보 입력이나 변경 (사용자가 직접)
3. **크몽 밖 연락처를 적지 않는다:** 전화번호, 카카오톡 ID, 이메일, 외부 링크 (크몽 규정 위반 → 계정 제재)
4. 문구는 **부록 원문 그대로** 넣는다. 글자 수 제한에 걸리면 뜻을 유지한 채 줄이고, 줄인 문장을 사용자에게 보여준다.
5. 모르는 칸(사업자 정보, 경력, 자격증 등)은 **지어내지 않고 비워 둔 뒤** 사용자에게 묻는다.
6. 파일 업로드 창(내 PC 파일 선택)은 Claude가 조작하기 어려울 수 있다 → 어떤 파일을 어떤 순서로 올릴지 안내하고, 선택은 사용자가 한다.
7. 각 단계가 끝날 때마다 **무엇을 입력했는지 짧게 보고**한다.

## 1. 준비물 (사용자가 먼저)

- [ ] 크롬에서 크몽 로그인 완료
- [ ] 이미지 파일을 PC에 내려받기: 저장소 `kmong-studio/assets/` 폴더
  - 썸네일: `thumb-main.png`(대표), `thumb-included.png`, `thumb-packages.png`, `thumb-bank.png`, `thumb-process.png`
  - 상세페이지: `d01.png` ~ `d11.png`
- [ ] 프로필 사진(로고) 이미지 1장 (없으면 이번엔 건너뜀)
- [ ] 결정: VAT 표기(포함/별도), 사업자 여부

---

## 2. 전문가 전환 & 프로필

1. 크몽 우측 상단 프로필 → **전문가로 전환** (이미 전문가면 건너뜀)
2. 마이크몽(전문가) → **프로필 관리**
   - 닉네임: `뚝딱컷스튜디오` ← (`뚝딱컷`은 이미 사용 중) **한 번 정하면 바꾸기 어려움. 입력 후 저장 전에 반드시 사용자 확인**
   - 한 줄 소개: [부록 A] 3번
   - 소개 본문: [부록 A] 4번
   - 프로필 사진: 사용자가 로고 파일 선택
3. **전문가 정보** (분야·스킬·툴·연락 가능 시간): [부록 A] 5번 표
   - 경력·자격증은 **사용자에게 물어서** 실제 내용만
4. ⏸ 저장 전 확인 → 저장 → 보고

---

## 3. 서비스 등록 (메인 서비스)

마이크몽(전문가) → 서비스 관리 → **서비스 등록**

| 순서 | 칸 | 넣을 내용 |
|---|---|---|
| 1 | 카테고리 | 영상·사진·음향 > AI 영상 > **AI 광고 영상** |
| 2 | 서비스 제목 | [부록 B] 1번 **메인** 제목 |
| 3 | 검색 태그 | [부록 B] 2번 (개수 제한까지) |
| 4 | 대표 이미지 | `thumb-main.png` |
| 5 | 추가 이미지 | `thumb-included.png` → `thumb-packages.png` → `thumb-bank.png` → `thumb-process.png` 순서 |
| 6 | 패키지 사용 | **3단계(STANDARD/DELUXE/PREMIUM) 켜기** |
| 7 | 패키지 이름·설명 | **[부록 C] B번** 패키지 설명 3개 |
| 8 | 가격 | STANDARD **75,000** / DELUXE **150,000** / PREMIUM **300,000** |
| 9 | 작업일 | 2일 / 3일 / 5일 |
| 10 | 수정 횟수 | 1회 / 2회 / 3회 |
| 11 | 패키지 체크 항목 | 상업적 이용 ○(전부), 원본 파일 ✕(옵션), 스크립트/내레이션 ○, 배경음악 ○ — 화면에 있는 항목만 |
| 12 | 추가 옵션 | [부록 B] 5번 표 (크몽이 지원하는 옵션 형태에 맞춰. 안 되는 건 사용자에게 보고) |
| 13 | 서비스 설명 | 맨 위에 `detail-one.jpg` 이미지 1장 (사용자가 파일 선택) → 그 아래 **[부록 C] A번** 텍스트 원문 |
| 14 | FAQ | [부록 B] 7번 |
| 15 | 구매 시 요청사항 | [부록 B] 8번 |
| 16 | 수정·재진행 안내 / 취소·환불 규정 | **[부록 C] C번 · D번** |

- DELUXE(1분 컷)에 **추천/BEST 표시**가 가능하면 켠다
- ⏸ **검수 요청(제출) 전 반드시 멈춤** → 미리보기 화면을 사용자와 같이 확인 → 사용자가 "제출" 하면 누름

## 4. 등록 후 체크

- [ ] 서비스 미리보기에서 썸네일 글자가 잘리지 않는지
- [ ] 패키지 가격 3개가 7.5만 / 15만 / 30만인지
- [ ] 설명 본문 이미지 순서가 d01 → d11인지
- [ ] 크몽 앱 푸시 알림 ON (사용자 휴대폰)
- [ ] 부재 시 자동 응답 문구 등록 (아래 5-1)

## 5. 매일 운영 (주문·메시지)

### 5-1. 부재 시 자동 응답 (한 번만 등록)
```
안녕하세요, AI 광고 스튜디오 뚝딱컷입니다 :)
지금 제작에 집중하고 있어 확인 후 빠르게 답변드리겠습니다.

기다리시는 동안 아래 3가지만 남겨주시면 바로 방향 제안까지 드릴게요.
1) 브랜드/제품 한 줄 소개
2) 영상 사용처 (유튜브 광고 / 릴스·숏츠 / 홈페이지 / 행사 등)
3) 희망 납품일
```

### 5-2. 새 메시지가 오면
1. 크몽 메시지함에서 **안 읽은 대화**를 연다
2. 고객 원문을 읽고 **답장 초안**을 쓴다. 기준:
   - 첫 답장엔 반드시 가격 안내 문장 포함:
     > 뚝딱컷은 계산이 하나뿐입니다. 영상 길이(분) × 150,000원이 최종 금액이고, 컷 수 제한 없이 AI 성우 내레이션·대본·BGM·효과음·자막까지 전부 포함입니다. 15초보다 짧은 영상 한 편이면 숏컷(75,000원)으로도 가능합니다.
   - 고객 업종에 맞는 **컨셉 한 줄 3개** 제안 + 추천 패키지 + "결제 전에 무료 시안 1컷을 먼저 보내드릴게요"
   - 할인 요청 → 할인 대신 길이 조정·분 쪼개기 제안
   - 실존 인물·연예인 합성, 타사 로고 요청 → 정중히 거절하고 가상 모델 제안
3. ⏸ 초안을 입력창에 넣고 **전송 전 멈춤** → 사용자 확인 후 전송
4. 대화 내용을 사용자에게 요약 보고 (저장소 `kmong-studio/clients/<고객명>/log.md`에 기록하도록)

### 5-3. 하지 않는 것
- 주문 수락·거절·취소·환불, 견적서 발송, 금액 변경은 **사용자 확인 없이 누르지 않는다**
- 고객에게 파일 링크(구글드라이브 등)를 보내지 않는다 — 크몽 안 파일 첨부만

## 6. 막히면

- 로그인 풀림·본인인증 요구 → 멈추고 사용자에게 넘김
- 원하는 칸이 없음 → 가장 가까운 칸을 제안하고 사용자에게 확인
- 크몽이 문구를 거절(금칙어 등) → 문제 단어를 알려주고 대체 문장 제안
