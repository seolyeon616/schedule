# FILM 01 「물의 기억」 — 편집 가이드 (명품 화장품 광고 톤)

> 영상 10컷을 다 만든 뒤 보는 문서입니다. 목표: **해외 명품 스킨케어 광고처럼 조용하고, 비싸 보이고, 글자가 거의 없는 45초.**

---

## 0. 명품 광고의 규칙 (이것만 지키면 절반은 끝)

| 하는 것 | 하지 않는 것 |
|---|---|
| 글자는 **영상 전체에 3번만** | 장면마다 자막, 효과음 자막, 설명 자막 |
| 작고 가는 글씨, **자간 넓게**, 화면 가운데 | 굵은 글씨, 그림자·외곽선, 화려한 색 |
| **천천히 나타났다 사라짐** (페이드) | 타자 치듯 나오기, 튀어나오기, 흔들기 효과 |
| 컷은 **그냥 붙이기** (하드컷) | 화면 밀기·회전·번쩍이는 전환 효과 |
| 내레이션 **딱 한 줄**, 속삭이듯 | 계속 설명하는 내레이션 |
| 음악은 조용히, **소리(물·얼음·비)가 주인공** | 신나는 음악, 큰 음악 |
| 여백과 정적 (0.5초 조용한 순간) | 화면을 꽉 채우는 정보 |

> 글자가 적을수록 비싸 보입니다. "뭔가 더 넣고 싶다"는 느낌이 들면 빼는 게 정답입니다.

## 1. 편집 프로그램

- **CapCut PC (추천, 무료):** 쉽고 빠름. 컷 자르기·역재생·속도·페이드·색 보정 다 됨.
- **DaVinci Resolve (무료):** 색 보정이 더 정교함. 익숙하면 이쪽.
- 폰트는 **상업 이용 무료(OFL)** 인 것만 설치해서 사용 (편집 프로그램 기본 폰트는 라이선스가 불분명할 수 있음):
  - 한글: **Noto Serif KR** (Light / Regular)
  - 영문 로고: **Cormorant Garamond** (Light / Medium)
  - 작은 영문: **Pretendard Light** 또는 Cormorant Garamond
  - 설치한 폰트가 CapCut 목록에 안 보이면 DaVinci Resolve에서 글자 작업을 하세요.

## 2. 타임라인 (16:9 · 1920×1080 · 24fps · 45초)

| 컷 | 시간 | 원본에서 쓸 부분 | 처리 |
|---|---|---|---|
| #1 물방울 훅 | 0:00–0:03 | 떨어지는 영상 전체 | **역재생** 후 마지막 3초 (물방울이 떠올라 가운데 멈춤) |
| #2 물방울 속으로 | 0:03–0:07 | 0.0–2.8초 + 6.0–7.2초 | 두 조각을 붙이고 이음새에 물 통과 "우웅" 효과음 |
| #3 빙하 속 물 | 0:07–0:11 | 1.5–5.5초 | 그대로 |
| #4 폭포 다이브 | 0:11–0:15 | 1.5–7.5초 | **150% 속도** |
| #5 이끼 숲 이슬 | 0:15–0:19 | 방울이 잎 끝에서 **떨어지는 순간에 끝나는** 4초 | 폭포 소리를 **뚝 끊고** 숲 소리로 |
| #6 도시 유리창 | 0:19–0:23 | 물방울이 유리에 **부딪히는 순간부터** 4초 | #5 떨어짐 → #6 부딪힘 매치 컷 |
| #7 창가의 여인 | 0:23–0:29 | **눈을 뜨는 순간이 0:27 근처**에 오게 6초 | 머리색 살짝 어둡게 |
| #8 세럼 한 방울 | 0:29–0:35 | 방울 맺힘 → 떨어짐 → 퍼짐 6초 | 방울을 #1과 **같은 크기·위치**로 (확대/이동) |
| #9 제품 히어로 | 0:35–0:41 | 병 모양이 가장 안정적인 6초 | 끝 8프레임 **검은 화면으로 페이드** |
| #10 엔드 타이틀 | 0:41–0:45 | 물방울 떨어짐 → 파문 → 잔잔 | 여기에 타이틀 |

- 컷 전환은 **전부 하드컷**, 예외는 #9 → #10 (검은 화면으로 페이드) 하나뿐.
- 각 컷의 원본 구간은 영상을 올려주시면 Claude가 프레임을 보고 정확히 정해 드립니다.

## 3. 글자 (전체 3번)

| 순서 | 시간 | 글자 | 스타일 |
|---|---|---|---|
| ① | 0:08.0–0:10.0 | `10,000 YEARS AGO` | Pretendard Light, 화면 높이의 약 2%, **자간 +40%**, 흰색 70%, 하단 중앙(하단 10% 위), 0.5초 페이드 인·아웃 |
| ② | 0:41.5–0:43.0 | `당신의 피부에 닿기까지, 1만 년.` | Noto Serif KR Light, 화면 높이의 약 3%, 자간 +10%, 흰색 90%, 화면 정중앙, 0.6초 페이드 |
| ③ | 0:43.2–0:45 | `AURÉA` + 아래 작게 `GLACIAL ORIGIN SERUM` | AURÉA: Cormorant Garamond Light, 화면 높이의 약 6%, **자간 +30%**, 샴페인 골드 `#C9A96E` · 아래 줄: 화면 높이 1.5%, 자간 +60%, 흰색 60%. 파문이 잔잔해질 때 천천히 페이드 인 |

- 그림자·외곽선·배경 박스 **없음**.
- 내레이션 자막은 **넣지 않습니다** (명품 광고는 대사 자막을 거의 쓰지 않음). SNS 무음 재생용 버전만 따로 만들 때 #8에 작은 자막 1줄.
- ①은 선택 사항: 더 미니멀하게 가려면 빼도 됩니다.

## 4. 소리

**구성:** 효과음(주인공) + 조용한 BGM + 내레이션 1줄

- **효과음:** Veo가 만든 소리를 기본으로, 약하면 `FILM01_물의기억_프롬프트시트.md` 5번의 효과음 프롬프트로 보강.
- **BGM:** 같은 문서 4번 BGM 프롬프트 (상업 이용 가능한 플랜으로 생성). 0–7초는 거의 무음 → #7부터 현악이 차오름 → #10에서 피아노 한 음으로 끝.
- **내레이션 (0:30 전후, #8에서 한 줄만):**
  ```
  1만 년을 기다린, 한 방울.
  ```
  여성, 낮은 톤, 속삭이듯 천천히. 상업 이용 가능한 AI 보이스로 생성, 앞에 0.3초 숨 여백.
- **정적:** #4 폭포 굉음이 끝나고 #5 시작 전 **0.3초 완전 무음**을 넣으면 고급스러움이 확 올라갑니다.
- **볼륨:** 전체 약 −14 LUFS(유튜브 기준), 피크 −1dB 이하. 내레이션이 음악보다 항상 또렷하게.

## 5. 색 (한 편처럼 보이게)

- 전체에 **같은 보정**을 한 번에 적용 (조정 레이어):
  - 채도 −10, 대비 약간 낮게, 검은색을 살짝 띄우기 (필름 느낌)
  - 그레인 3% 정도
- **온도 변화로 이야기하기:** #1–#6은 차갑게(청록·네이비), #7부터 따뜻한 금빛 테두리 조명이 살아나게 → "시간이 흘러 지금, 당신에게 닿았다"
- 컷 사이에 **밝기가 튀는 곳**만 개별 보정.
- 16:9 위아래에 검은 띠(시네마 비율)를 넣으면 더 영화 같아지지만, 크몽 썸네일·쇼츠 활용을 생각하면 **넣지 않는 것 추천**.
