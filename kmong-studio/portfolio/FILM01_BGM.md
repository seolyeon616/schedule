## A. Glacial Hymn — 가장 무난한 명품 톤 ★추천

- **느낌:** 피아노 + 유리 하모닉스 + 현악이 천천히 차오름. 설화수·라메르 같은 헤리티지 스킨케어 광고의 정석.
- **Style**
```
minimal cinematic ambient, felt piano, glass harmonics, soft string swell, luxury skincare commercial, slow 60 bpm, instrumental, elegant, restrained
```
- **Lyrics 칸 (구조 지시)**
```
[Instrumental]
[Intro: near silence, a single crystalline glass tone, deep sub bass swell]
[Build: sparse felt piano notes, glacial ambience, a sense of ancient time]
[Break: sudden silence]
[Verse: soft piano returns, gentle rain-like textures]
[Climax: warm legato strings rise to an emotional gentle peak]
[Outro: everything resolves to one resonant piano note with a long reverb tail]
[End]
```

## B. Silk & Time — 가장 감성적

- **느낌:** 솔로 첼로 + 펠트 피아노. 여인 컷(#7)의 감정이 가장 살아남.
- **Style**
```
intimate neoclassical, solo cello, felt piano, airy room reverb, slow 56 bpm, instrumental, tender, luxurious, minimal
```
- **Lyrics 칸**
```
[Instrumental]
[Intro: one long low cello note, quiet air]
[Build: slow felt piano motif, three notes repeating]
[Break: silence]
[Verse: cello melody enters softly]
[Climax: cello and piano together, warm and emotional, not loud]
[Outro: single piano note fading into silence]
[End]
```

## C. Crystal Pulse — 가장 모던 (해외 럭셔리 뷰티 느낌)

- **느낌:** 아주 낮은 심장 박동 같은 펄스 + 크리스털 아르페지오. 세련되고 차가운 도시적 럭셔리.
- **Style**
```
modern minimal electronic, soft sub pulse, crystalline arpeggio, airy pads, luxury fashion film, 70 bpm, instrumental, sleek, cold then warm
```
- **Lyrics 칸**
```
[Instrumental]
[Intro: silence, a single shimmering crystal pluck]
[Build: soft heartbeat-like sub pulse, crystalline arpeggio slowly layering]
[Break: hard cut to silence]
[Verse: arpeggio returns filtered, rain texture]
[Climax: warm analog pad opens up, pulse grows, glowing]
[Outro: pulse stops, one crystal tone rings out]
[End]
```

## D. Manyeon Heritage — 브랜드 정체성(한국)을 가장 잘 살림

- **느낌:** 가야금 하모닉스·대금 숨소리를 아주 절제해서 앰비언트 현악 위에 얹음. 설화수처럼 **한국 헤리티지를 세계 무대 톤으로**.
- **Style**
```
cinematic ambient with subtle Korean gayageum harmonics and daegeum breath, soft strings, luxury heritage brand film, slow 58 bpm, instrumental, serene, timeless
```
- **Lyrics 칸**
```
[Instrumental]
[Intro: near silence, a single gayageum harmonic, wind]
[Build: distant daegeum breath, soft string drone, ancient and calm]
[Break: silence]
[Verse: sparse gayageum plucks with piano]
[Climax: strings rise warmly under a gentle daegeum melody]
[Outro: one gayageum harmonic with long reverb]
[End]
```
